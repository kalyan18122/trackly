# Trackly: Local Delivery Management

1. Install Node.js (version 22 or newer) from nodejs.org.
2. Extract this folder somewhere outside OneDrive, for example C:\trackly-project
3. Double-click start.bat

Two windows open (backend and frontend) and the browser opens http://localhost:5500.
Keep both windows open while using the app.

Logins: admin 9999999999 / admin123, delivery boy 9848011111 / boy123
Tracking IDs: TRK1001, TRK2002, TRK3003

Manual run: in backend run "npm install" then "npm start"; in frontend run "npm start".
